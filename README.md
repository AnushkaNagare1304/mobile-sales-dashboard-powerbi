# 📊 Mobile Sales Dashboard (Power BI)

## 📖 Overview
This project presents an interactive Power BI dashboard designed to analyze mobile sales performance across different dimensions such as brand, model, payment method, and time.

The dashboard helps identify sales trends, top-performing products, and customer behavior patterns.

---

## 🚀 Features
- Interactive month-wise navigation panel
- Dynamic filters for Mobile Model, Payment Method, and Brand
- KPI cards showing:
  - Total Sales
  - Total Quantity
  - Total Transactions
  - Average Sales
- Monthly and day-wise sales trend analysis
- Payment method distribution
- Customer rating breakdown
- Top-selling mobile models analysis
- Brand-wise performance summary
